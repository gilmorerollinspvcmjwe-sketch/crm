## 一、联系人详情页设计

### 1.1 三栏布局概述

联系人详情页继承客户详情页的三栏布局结构。

布局：左侧操作区(240px) + 中间区域(flex) + 右侧关联信息(320px)

中间区域包含：
- AI概览卡片
- 最近活动时间线
- 关系变化卡片

右侧区域包含：
- 所属公司
- 关联交易列表（可折叠）
- 工单列表（可折叠）
- 最近活动

### 1.2 左侧操作按钮区

| 按钮 | 行为 | 权限 |
|------|------|------|
| 编辑联系人 | 打开编辑抽屉 | 编辑权限 |
| 删除联系人 | 确认弹窗后删除 | 管理员 |
| 发邮件 | 唤起邮件编辑 | 所有人 |
| 打电话 | 发起电话拨打 | 所有人 |
| 创建交易 | 跳转新建商机页，关联当前联系人 | 业务员 |
| 创建工单 | 跳转新建工单页，关联当前联系人 | 客服/业务员 |

### 1.3 中间区域 -- Tab 切换

#### Tab 1：Overview（联系人概览）

关键字段（优先级排序）：

| 字段 | 说明 |
|------|------|
| 姓名 | 联系人全名，主标识 |
| 职位 | 如：CEO、技术总监、采购经理 |
| 所属公司 | 关联的客户名称，点击跳转客户详情 |
| 部门 | 所属部门 |
| 手机 | 主要联系方式，带拨号图标 |
| 电话 | 座机或其他电话 |
| 邮箱 | 主要邮箱，带发邮件图标 |
| 决策角色 | 决策人 / 影响力人 / 使用者 / 技术评估人 |
| 地址 | 工作地址 |
| 备注 | 自由文本 |

#### Tab 2：Activity（活动时间线）

- 数据源：邮件、拨打电话、会议、聊天记录、跟进备注
- 筛选器：全部 / 邮件 / 电话 / 会议 / 聊天
- 每条记录显示：类型图标 + 时间 + 摘要 + 负责人 + 关联对象

#### Tab 3：AI Insights（AI 分析）

| 卡片 | 内容 |
|------|------|
| 联系人概览 AI | LLM 生成联系人关键信息摘要 |
| 关系变化 | 活跃度变化、决策人变动等 |
| 智能建议 | 跟进提醒、关联机会推荐 |

### 1.4 右侧关联信息区

| 模块 | 内容 | 展示方式 |
|------|------|---------|
| 所属公司 | 公司名称、行业、规模、区域 | 卡片，点击跳转 |
| 关联交易 (N) | 商机名称、金额、阶段、概率 | 可折叠列表 |
| 工单 (N) | 工单标题、状态、创建时间 | 可折叠列表 |
| 最近活动 | 最近 3 条活动记录 | 简洁列表 |

### 1.5 与客户详情页的差异点

| 维度 | 客户详情 | 联系人详情 |
|------|---------|-----------|
| 左侧操作 | 编辑/分配/删除/新建商机/新建联系人/新建跟进/加入公海/导出 | 编辑/删除/发邮件/打电话/创建交易/创建工单 |
| 首部标识 | 公司名称 + 行业 + 等级 | 姓名 + 职位 + 所属公司 |
| 关联公司 | 无（自身就是公司维度） | 所属公司（关联跳转） |
| AI概览侧重 | 公司价值、活跃度、风险 | 决策影响力、联系人变动、沟通价值 |
| 右侧关联 | 公司信息/交易/工单/联系人 | 所属公司/交易/工单/最近活动 |

## 二、交易（商机）详情页设计

交易（商机）详情页与联系人详情页保持一致的三栏布局，核心区别：

## 三、订单管理模块设计（新增）

### 3.1 订单 vs 合同的区别说明

| 维度 | 订单（Order） | 合同（Contract） |
|------|--------------|------------------|
| 定义 | 客户提交的商品/服务购买请求 | 双方正式签署的法律文件 |
| 状态 | Draft -> Confirmed -> Processing -> Shipped -> Delivered -> Completed | Draft -> Pending -> Signed -> Active -> Expired |
| 触发 | 客户下单、线上购买、销售录入 | 合同签署流程完成 |
| 内容 | 产品明细、数量、价格、交付信息 | 合同条款、签署人、生效日期、到期日期 |
| 金额 | 基于产品明细计算，可有折扣 | 固定金额或框架协议 |
| 交付 | 有物流/交付环节 | 无物流，纯文档管理 |
| 关联 | 关联客户、合同（可选）、回款计划 | 关联客户、商机 |
| 用途 | 执行层面，跟进实物/服务交付 | 法律层面，保障双方权益 |

### 3.2 订单列表页设计

路由：/order/list

筛选器字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| 搜索 | 文本输入 | 订单号、客户名称模糊搜索 |
| 状态 | 单选下拉 | Draft / Confirmed / Processing / Shipped / Delivered / Completed / Cancelled |
| 客户 | 关联选择 | 关联的客户 |
| 日期范围 | 日期范围选择 | 下单时间区间 |
| 金额范围 | 数字范围 | 订单金额区间 |

表格列定义：

| 列名 | 宽度 | 说明 |
|------|------|------|
| 选择框 | 40px | 批量操作 |
| 订单号 | 140px | ORD-YYYY-NNNNN 格式 |
| 客户名称 | 180px | 关联的客户名称，点击跳转客户详情 |
| 金额 | 120px | 带货币格式，右对齐 |
| 状态 | 100px | 状态标签，颜色区分 |
| 下单时间 | 120px | YYYY-MM-DD 格式 |
| 交付时间 | 120px | YYYY-MM-DD 格式，未交付显示 "-" |
| 操作 | 60px | ... 更多操作按钮 |

### 3.3 订单详情页（三栏布局）

路由：/order/:id

中间区域 Tab：

| Tab | 内容 |
|-----|------|
| Overview | 订单基本信息 + 物流信息 |
| Products | 产品明细列表（含数量、单价、小计） |
| Delivery | 物流详情 + 签收记录 |
| Activity | 活动时间线（状态变更记录） |

### 3.4 订单状态流转

Draft（草稿）-> Confirmed（已确认）-> Processing（处理中）-> Shipped（已发货）-> Delivered（已送达）-> Completed（已完成）

任意状态 -> Cancelled（已取消）

状态颜色规范：

| 状态 | 前景色 | 背景色 | 说明 |
|------|--------|--------|------|
| Draft | #637381 | #F5F5F5 | 草稿 |
| Confirmed | #0288D1 | #E1F5FE | 已确认 |
| Processing | #ED6C02 | #FFF3E0 | 处理中 |
| Shipped | #7B1FA2 | #F3E5F5 | 已发货 |
| Delivered | #2E7D32 | #E8F5E9 | 已送达 |
| Completed | #1B5E20 | #C8E6C9 | 已完成 |
| Cancelled | #D32F2F | #FFEBEE | 已取消 |

### 3.5 路由设计

| 路由 | 页面 | 说明 |
|------|------|------|
| /order/list | 订单列表页 | 展示所有订单 |
| /order/create | 新建订单页 | 创建新订单 |
| /order/:id | 订单详情页 | 查看/编辑订单详情 |

### 3.6 菜单位置

订单管理（一级菜单）
+-- 订单列表（二级菜单）-> /order/list

## 四、自定义页面设计（Page Builder）

### 4.1 功能概述

自定义页面（Page Builder）允许用户对所有对象详情页（客户/联系人/商机/订单/工单等）进行布局自定义，保存为多个视图，支持视图切换和默认视图设置。

核心特性：
- 左中右三栏布局，每栏可独立配置
- 每栏可添加/移除/排序卡片
- 多个视图可保存，适用于不同使用场景（如"销售视图"、"客服视图"）
- 视图可切换，可设默认
- 支持自定义页面布局的对象：客户、联系人、商机、订单、工单、自定义对象

### 4.2 页面构建器界面设计

入口：对象管理 -> 详情页视图管理 -> 编辑视图（调用 Page Builder）

布局结构：
- 左侧：组件面板（240px），可拖拽的卡片类型列表
- 中间：三栏画布（flex: 1），可拖入卡片并排序
- 右侧：属性配置面板（280px），配置选中卡片的显示属性

### 4.3 卡片类型详细定义

#### 4.3.1 属性卡片（Property Card）

展示对象的指定属性字段。

| 配置项 | 说明 |
|--------|------|
| 卡片标题 | 自定义显示名称 |
| 显示属性 | 多选，可选择对象的所有属性 |
| 布局方式 | 两列/三列网格 |
| 折叠状态 | 默认展开/默认折叠 |

#### 4.3.2 关联卡片（Association Card）

展示关联对象列表。

| 配置项 | 说明 |
|--------|------|
| 卡片标题 | 如"联系人"、"商机"、"工单" |
| 关联对象 | 选择关联的对象类型 |
| 显示字段 | 选择列表中每项显示哪些字段 |
| 显示数量 | 默认显示 N 条，点击展开更多 |
| 显示类型 | 卡片列表 / 简洁列表 / 仅显示数量 |
| 筛选条件 | 可选，限制显示符合条件的记录 |

#### 4.3.3 活动卡片（Activity Card）

展示活动时间线。

| 配置项 | 说明 |
|--------|------|
| 卡片标题 | 默认"最近活动" |
| 筛选条件 | 全部/邮件/电话/会议/聊天 |
| 显示数量 | 默认显示 5 条 |
| 折叠状态 | 默认展开/默认折叠 |

#### 4.3.4 AI 分析卡片（AI Insights Card）

展示 AI 生成的分析内容。

| 配置项 | 说明 |
|--------|------|
| 卡片类型 | 概览/关系变化/智能建议 |
| 刷新按钮 | 是否显示刷新按钮 |
| 折叠状态 | 默认展开/默认折叠 |

#### 4.3.5 图表卡片（Chart Card）

展示数据图表。

| 配置项 | 说明 |
|--------|------|
| 图表类型 | 折线图/柱状图/饼图/漏斗图/数字指标卡 |
| 数据源 | 关联对象的聚合数据 |
| 标题 | 图表标题 |

#### 4.3.6 自定义 HTML 卡片（Custom HTML Card）

嵌入自定义 HTML 内容。

| 配置项 | 说明 |
|--------|------|
| HTML 内容 | 富文本编辑器，支持插入变量占位符 |
| CSS 样式 | 自定义样式（可选） |

### 4.4 拖拽操作

| 操作 | 行为 |
|------|------|
| 拖拽卡片到栏 | 从组件面板拖拽卡片到左/中/右栏的指定位置 |
| 栏内排序 | 在同一栏内上下拖拽卡片改变顺序 |
| 跨栏移动 | 将卡片从一栏拖拽到另一栏 |
| 移除卡片 | 拖出画布区域，或点击卡片上的删除按钮 |

拖拽约束：
- 左侧栏：宽度固定 240px，不可调整
- 中间栏：flex: 1，占据剩余空间
- 右侧栏：宽度固定 320px

### 4.5 保存视图

保存为新视图 Modal：

| 配置项 | 说明 |
|--------|------|
| 视图名称 | 必填 |
| 视图描述 | 可选 |
| 设为默认视图 | 复选框 |
| 可见范围 | 仅我可见 / 所有人可见 / 指定角色可见 |

### 4.6 视图切换

视图切换器（下拉选择）：
- 当前视图名称 + 下拉箭头
- 列出所有可用视图（个人视图优先）
- 可快速创建新视图（点击"+"图标）
- 切换时页面布局即时更新，无需刷新

### 4.7 默认视图设置

| 设置项 | 说明 |
|--------|------|
| 系统默认 | 每个对象有一个系统默认视图（不可删除） |
| 个人默认 | 用户可设置自己的默认视图（覆盖系统默认） |
| 角色默认 | 管理员可为特定角色设置默认视图 |

优先级：个人默认 > 角色默认 > 系统默认

#### 5.1.2 自定义属性列表
