## 优化概述

### 优化目标

提升客户详情页的工业级质感，参考 Salesforce/HubSpot 等专业 CRM 产品的设计规范，打造专业、高效、美观的用户体验。

### 核心改进点

| 问题 | 优化方案 | 优先级 |
|------|----------|--------|
| 左侧信息卡片太素 | 增加头像区域、关键指标卡片、分组信息展示 | 🔴 高 |
| 中间内容区域空白太多 | 增加数据卡片行、活动流时间线 | 🔴 高 |
| Tab 设计不够专业 | 使用带图标 + 计数的专业 Tab 组件 | 🟡 中 |
| 缺少关键信息概览 | 添加 4 个核心指标卡片 | 🔴 高 |
| 缺少时间线/活动流 | 实现垂直时间线组件展示活动 | 🔴 高 |
| 右侧关联信息简陋 | 增加可折叠卡片、决策角色徽章、优先级标识 | 🟡 中 |

## 详细设计说明

### 颜色规范

| 用途 | 色值 | Tailwind | 使用场景 |
|------|------|----------|----------|
| 主色 | #0f172a | slate-900 | 标题、主要文字 |
| 强调色 | #3b82f6 | blue-500 | 链接、选中状态、主按钮 |
| 成功 | #10b981 | emerald-500 | 成交状态、正向指标 |
| 警告 | #f59e0b | amber-500 | 警告状态、中优先级 |
| 危险 | #ef4444 | red-500 | 失败状态、高优先级、删除 |
| 背景 | #f8fafc | slate-50 | 页面背景 |
| 卡片 | #ffffff | white | 卡片背景 |
| 边框 | #e2e8f0 | slate-200 | 边框、分隔线 |

### 字体规范

| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| 大标题 | 20px | 600 | 页面标题、客户名称 |
| 标题 | 16px | 600 | 卡片标题、分组标题 |
| 正文 | 14px | 400 | 主要内容文字 |
| 辅助文字 | 12px | 400 | 标签、说明文字 |

### 间距规范

| 类型 | 值 | 使用场景 |
|------|-----|----------|
| 卡片内边距 | p-6 (24px) | 卡片内容区域 |
| 卡片间距 | gap-6 (24px) | 卡片之间 |
| 元素间距 | space-y-4 (16px) | 垂直元素间隔 |
| 紧凑间距 | space-y-2 (8px) | 列表项间隔 |

### 阴影规范

| 类型 | 类名 | 使用场景 |
|------|------|----------|
| 默认 | shadow-sm | 卡片默认阴影 |
| 悬浮 | shadow-md | Hover 状态 |
| 弹窗 | shadow-xl | 模态框、下拉菜单 |
