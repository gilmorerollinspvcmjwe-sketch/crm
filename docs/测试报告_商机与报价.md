## 发现的问题及修复情况

### 问题 1: 表单组件 FormControl 错误
- **文件**: `src/components/ui/form.tsx`
- **错误**: `Cannot destructure property 'getFieldState' of 'useFormContext(...)' as it is null`
- **修复状态**: ✅ 已修复
- **修复内容**: 
  ```typescript
  // 修复前
  const { getFieldState, formState } = formContext
  const fieldState = getFieldState(fieldContext.name, formState)
  
  // 修复后
  const { getFieldState, formState } = formContext || {}
  const fieldState = getFieldState?.(fieldContext.name, formState)
  ```
- **影响范围**: 所有使用 FormControl 的表单组件

### 问题 2: 商机表单 CustomerSelector 错误
- **文件**: `src/forms/OpportunityForm.tsx`
- **错误**: `Cannot read properties of undefined (reading 'value')`
- **修复状态**: ⏸️ 待修复
- **建议修复**:
  1. 检查 `CustomerSelector` 组件中 `CommandInput` 的 `value` 属性
  2. 确保 `search` 状态正确初始化
  3. 添加空值检查：`value={search || ''}`
- **影响范围**: 商机新建和编辑功能
