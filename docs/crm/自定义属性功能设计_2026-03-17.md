## 一、需求分析

### 1.1 模块需求概览

经过对现有 9 个核心业务模块的字段分析，确定以下模块需要支持自定义属性功能：

| 模块 | 优先级 | 现有字段数 | 自定义字段需求说明 |
|------|--------|------------|-------------------|
| 客户管理 | P0 | 22 | 不同行业客户需要差异化字段 |
| 联系人 | P0 | 29 | 人员信息字段差异大 |
| 线索管理 | P1 | 28 | 不同来源线索需要不同跟进字段 |
| 商机管理 | P1 | 17 | 不同产品线商机字段差异 |
| 合同管理 | P2 | 25 | 合同条款可能需要自定义字段 |
| 产品库 | P1 | 15 | 不同类型产品有不同属性 |
| 报价单 | P2 | 14 | 可能需要自定义审批字段 |
| 工单系统 | P1 | 17 | 不同类型工单需要不同字段 |
| 活动管理 | P2 | 18 | 不同营销活动类型字段不同 |

## 三、数据结构设计

### 3.1 字段定义表结构

```typescript
/** 自定义字段定义 */
interface CustomField {
  /** 字段ID - 唯一标识 */
  id: string;
  /** 字段名称 - 用于API，字母数字下划线 */
  name: string;
  /** 显示标签 - 用于UI展示 */
  label: string;
  /** 字段类型 */
  type: FieldType;
  /** 绑定模块 - 模块标识数组 */
  modules: ModuleType[];
  /** 是否必填 */
  required: boolean;
  /** 选项列表 - 单选/多选时使用 */
  options?: string[];
  /** 选项集ID - 关联选项集管理 */
  optionsSetId?: string;
  /** 验证规则 */
  validation?: FieldValidation;
  /** 默认值 */
  defaultValue?: any;
  /** 占位符 */
  placeholder?: string;
  /** 排序序号 */
  sortOrder: number;
  /** 是否在列表中显示 */
  listVisible: boolean;
  /** 是否在详情中显示 */
  detailVisible: boolean;
  /** 是否启用 */
  enabled: boolean;
  /** 创建人 */
  createdBy: string;
  /** 创建时间 */
  createdAt: string;
  /** 最后修改人 */
  updatedBy?: string;
  /** 最后修改时间 */
  updatedAt?: string;
}

/** 字段类型枚举 */
type FieldType = 
  | 'text'        // 文本
  | 'textarea'    // 多行文本
  | 'number'      // 数字
  | 'date'        // 日期
  | 'datetime'    // 日期时间
  | 'select'      // 单选
  | 'multiselect' // 多选
  | 'switch'      // 开关
  | 'user'        // 人员
  | 'department'  // 部门
  | 'relation'    // 关联
  | 'file';       // 附件

/** 模块类型枚举 */
type ModuleType = 
  | 'customer'    // 客户
  | 'contact'     // 联系人
  | 'lead'        // 线索
  | 'opportunity' // 商机
  | 'contract'   // 合同
  | 'product'     // 产品
  | 'quote'       // 报价单
  | 'ticket'      // 工单
  | 'campaign';   // 活动

/** 字段验证规则 */
interface FieldValidation {
  unique?: boolean;        // 唯一性
  minLength?: number;      // 最小长度
  maxLength?: number;      // 最大长度
  min?: number;            // 最小值
  max?: number;            // 最大值
  pattern?: string;       // 正则表达式
  errorMessage?: string;  // 自定义错误消息
}

/** 选项集 */
interface OptionsSet {
  id: string;
  name: string;
  options: OptionItem[];
  createdBy: string;
  createdAt: string;
}

/** 选项项 */
interface OptionItem {
  value: string;   // 选项值
  label: string;   // 显示标签
  sortOrder: number; // 排序
}
```

### 3.2 字段值存储方案

**推荐方案**: JSON 字段存储

**实现方式**: 在各业务模块数据中增加 `customFields` 字段，类型为 JSON Object

```typescript
// 客户数据示例
interface Customer {
  id: string;
  name: string;
  // ... 标准字段
  
  /** 自定义字段值 - JSON格式存储 */
  customFields?: Record<string, any>;
}

// 示例数据
{
  "id": "cust_001",
  "name": "XX科技有限公司",
  "industry": "互联网/软件/IT 服务",
  "level": "A",
  // ... 标准字段
  
  // 自定义字段
  "customFields": {
    "customerType": "直客",
    "cooperationStartDate": "2023-01-15",
    "creditLimit": 500000,
    "vipFlag": true,
    "customerTags": ["重点客户", "战略合作"]
  }
}
```

**优点**:
- 灵活性高，无需数据库迁移
- 支持任意类型的自定义数据
- 开发成本低

**缺点**:

- 查询效率略低

### 4.2 表单集成方案

#### 4.2.1 动态表单渲染

在业务模块的表单页面中，通过以下方式集成自定义字段：

```typescript
// 表单组件结构
const CustomerForm = () => {
  // 1. 加载自定义字段定义
  const customFields = useCustomFields('customer');
  
  // 2. 渲染标准字段
  return (
    <Form>
      {/* 标准字段 */}
      <Input name="name" label="客户名称" />
      <Select name="industry" label="行业" />
      
      {/* 自定义字段 - 动态渲染 */}
      {customFields.map(field => (
        <DynamicField 
          key={field.id} 
          field={field} 
          value={formValues.customFields?.[field.name]}
          onChange={(value) => handleCustomFieldChange(field.name, value)}
        />
      ))}
    </Form>
  );
};
```

| date | DatePicker | name, label, format |
| datetime | DatePicker | name, label, showTime, format |
| select | Select | name, label, options |
| multiselect | MultiSelect | name, label, options |
| switch | Switch | name, label |
| user | UserSelect | name, label, placeholder |
| department | DepartmentTreeSelect | name, label |

#### 4.3.2 列表渲染

```typescript
// 列表列定义
const columns = [
  // 标准列
  { title: '客户名称', dataIndex: 'name' },
  { title: '行业', dataIndex: 'industry' },
  
  // 自定义字段列 - 动态渲染
  ...customFields
    .filter(f => f.listVisible)
    .map(field => ({
      title: field.label,
      dataIndex: ['customFields', field.name],
      render: (value) => renderCustomFieldValue(field, value)
    }))
];
```
