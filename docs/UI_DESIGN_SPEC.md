## 1. 当前问题分析

通过代码审查和页面结构分析，归纳出当前设计的 **10 个核心问题**：

### 问题 1：emoji 过度使用，视觉噪音严重
- 侧边栏菜单项全部带 emoji 前缀（📊🔰🎯📋📦📈🤖📢🔗⚙️）
- 卡片标题、Tab 标签、统计数值均有 emoji
- **影响**：显得不专业，干扰信息获取，与 HubSpot 的简洁风格背道而驰

### 问题 2：信息密度过低
- 页面统一 `padding: 24px`，内容区 `margin: 24px 16px`
- 详情页大量使用宽松的 Descriptions 布局
- **影响**：用户需要大量滚动才能看到有效数据，笔记本屏幕效率极低

### 问题 3：无折叠设计，所有信息平铺
- 客户详情页的 Tab 区域默认展开所有字段
- 基本信息用 `Descriptions column={3}` 一次性展示 20+ 字段
- **影响**：关键信息被稀释，次要信息抢占视觉焦点

### 问题 4：导航层级混乱
- 菜单同时使用 emoji + ant icon + 文字三种标识
- 二级菜单最多达 8 项，无分组折叠指示
- **影响**：用户难以快速定位目标，功能发现性差

### 问题 5：颜色系统不统一
- Tag 颜色直接使用 Ant Design 的 `'red'` `'orange'` 等字符串
- 阶段颜色在 SalesFunnel 中硬编码为十六进制值
- **影响**：主题切换困难，视觉风格无法一致性调整

### 问题 6：无响应式适配
- Content 区域固定 `minHeight: 280`，侧边栏固定宽度
- 表格 `scroll={{ x: 1200 }}` 仅支持横向滚动
- **影响**：小屏和笔记本用户需要左右滚动，体验差

### 问题 7：表格功能简陋
- 无列配置、密度切换、快捷操作列
- 分页仅支持基础翻页，无跳页、快速范围选择
- **影响**：不符合 B 端用户高效数据处理需求

### 问题 8：缺少快捷操作入口
- 详情页仅在顶部放置「编辑、分配、删除」三个按钮
- 没有 inline 操作、行内编辑、快捷编辑抽屉
- **影响**：常用操作路径过长，效率低

### 问题 9：表单弹窗过重
- 新建/编辑客户使用全屏 Modal（width: 600）
- 表单未经分组，所有字段平铺（15+ 字段）
- **影响**：用户认知负担重，填写效率低

### 问题 10：仪表盘 Dashlet 无优先级
- 所有 Dashlet 平铺展示，无重要性区分
- 缺少快捷视图切换（我的今日 / 经理视图 / 自定义）
- **影响**：不同角色用户看到相同内容，无法聚焦核心数据

## 2. 设计原则

参考 **HubSpot Canvas Design System**，确立以下 5 条核心原则：

### 2.1 Clear（清晰）
- **视觉层次**：用字号、字重、颜色灰度区分信息优先级，而非 emoji 或装饰色块
- **功能优先级**：常用功能突出展示，次要功能收纳到折叠区或二级菜单
- **上下文感知**：每个页面聚焦当前任务，相关操作就近放置

### 2.2 Human（人性化）
- **跨文化共鸣**：避免特定文化符号（emoji），使用通用图标和文案
- **有趣的微交互**：按钮悬停、展开折叠、行内编辑等交互给予即时反馈
- **友好的提示语**：错误提示用自然语言

### 2.3 Inbound（集客方法论）
- **引导正确操作**：通过空状态引导、进度指示器引导用户完成目标路径
- **清晰的价值传递**：每个页面的第一屏应展示最关键的数据摘要

### 2.4 Integrated（整合）
- **统一的设计系统**：颜色、字体、间距、圆角、阴影均有明确规范，不可随意发挥
- **流畅的工作流**：页面跳转、抽屉滑出、Modal 弹出等过渡平滑连贯

### 2.5 Collaborative（协作）
- **多人协作友好**：记录级别的负责人、创建时间、修改历史可见
- **数据共享便捷**：列表支持批量选择和批量操作，减少重复操作

## 3. 设计规范

### 3.1 颜色系统

#### 主色（Primary）
| Token | 色值 | 用途 |
|-------|------|------|
| `--color-primary` | `#2359A2` | 主按钮、选中态、链接 |
| `--color-primary-hover` | `#1E4A8A` | 主按钮悬停 |
| `--color-primary-subtle` | `#EBF2FA` | 选中行背景、轻量标签 |

#### 辅助色（Secondary）
| Token | 色值 | 用途 |
|-------|------|------|
| `--color-secondary` | `#6B7785` | 次要按钮、辅助文字 |
| `--color-secondary-hover` | `#5A6675` | 次要按钮悬停 |

#### 状态色（Status）
| Token | 色值 | 用途 |
|-------|------|------|
| `--color-success` | `#2E7D32` | 成交、赢单、已支付 |
| `--color-warning` | `#ED6C02` | 即将到期、待处理 |
| `--color-danger` | `#D32F2F` | 逾期、输单、删除 |
| `--color-info` | `#0288D1` | 进行中、新建、待确认 |

#### 中性色（Neutral）
| Token | 色值 | 用途 |
|-------|------|------|
| `--color-text-primary` | `#212B36` | 标题、主要文字 |
| `--color-text-secondary` | `#637381` | 辅助说明文字 |
| `--color-text-disabled` | `#919EAB` | 禁用文字 |
| `--color-border` | `#DFE3E8` | 边框、分割线 |
| `--color-border-light` | `#F0F2F5` | 表格斑马纹、分组背景 |
| `--color-bg-page` | `#F4F5F7` | 页面背景 |
| `--color-bg-card` | `#FFFFFF` | 卡片背景 |
| `--color-bg-hover` | `#F5F6F8` | 行悬停、按钮悬停背景 |

#### 客户等级色（Domain）
| 等级 | 前景色 | 背景色 |
|------|--------|--------|
| A | `#D32F2F` | `#FFEBEE` |
| B | `#ED6C02` | `#FFF3E0` |
| C | `#0288D1` | `#E1F5FE` |
| D | `#637381` | `#F5F5F5` |

### 3.2 字体系统

```
--font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
--font-family-mono: 'JetBrains Mono', 'Fira Code', monospace;
```

| 用途 | 字号 | 字重 | 行高 |
|------|------|------|------|
| 页面标题 (H1) | 20px | 600 | 28px |
| 卡片标题 (H2) | 16px | 600 | 24px |
| 区块标题 (H3) | 14px | 600 | 20px |
| 正文 | 14px | 400 | 22px |
| 辅助说明 | 13px | 400 | 20px |
| 表格内容 | 13px | 400 | 18px |
| 标签/按钮 | 13px | 500 | 18px |
| 小字/提示 | 12px | 400 | 16px |

### 3.3 间距系统

基于 **4px 基准网格**：

| Token | 值 | 用途 |
|-------|----|------|
| `--space-1` | 4px | 紧凑元素内部间距 |
| `--space-2` | 8px | 表格单元格 padding |
| `--space-3` | 12px | 表单项之间 |
| `--space-4` | 16px | 区块内间距 |
| `--space-5` | 20px | 卡片内 padding |
| `--space-6` | 24px | 页面级间距 |
| `--space-8` | 32px | 区块之间间距 |

**布局间距规则：**
- 页面边距：桌面 24px，笔记本 16px
- 卡片间距：相邻卡片 12px
- 表格行高：紧凑 40px，默认 48px，宽松 56px

### 3.4 圆角系统

| Token | 值 | 用途 |
|-------|----|------|
| `--radius-sm` | 4px | 标签、小按钮、输入框 |
| `--radius-md` | 6px | 按钮、卡片、Modal |
| `--radius-lg` | 8px | 大卡片、弹窗 |
| `--radius-pill` | 9999px | 徽章、胶囊按钮 |

### 3.5 阴影系统

| Token | 值 | 用途 |
|-------|----|------|
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,0.06)` | 表格行悬停 |
| `--shadow-md` | `0 2px 4px rgba(0,0,0,0.08)` | 下拉菜单、popover |
| `--shadow-lg` | `0 4px 12px rgba(0,0,0,0.12)` | 抽屉、Modal |
| `--shadow-xl` | `0 8px 24px rgba(0,0,0,0.16)` | 确认删除等重要弹窗 |

### 3.6 图标使用规范

**图标库**：统一使用 `@ant-design/icons` 或 Lucide React

**尺寸规范：**
- 行内图标（表格操作列）：14px
- 按钮图标：14px（与文字同高）
- 导航图标：16px
- 页面级图标：20px

**颜色规范：**
- 导航激活态：使用 `--color-primary`
- 操作图标：默认 `#637381`，悬停变为主题色
- 状态图标：使用对应状态色

**禁用场景：**
- 菜单项前缀禁止加 emoji
- 页面标题前缀禁止加 emoji
- 统计数值前缀禁止加 emoji
- 使用图标 + 文字组合表达含义

## 4. 页面设计方案

### 4.1 客户列表页

#### 旧版问题
- 客户名称列过宽（200px），行业列过窄（150px）
- 无批量操作栏，仅靠按钮触发
- 筛选器在 Card 内部，未与列表分离

│  客户列表                                            [导出] [+ 新建] │
├─────────────────────────────────────────────────────────────────────┤

│ ☐  │ 客户名称     │ 行业  │规模│来源│等级│状态  │ 负责人   │ 操作   │

**关键改进：**
1. **筛选器独立成行**：不再包裹在 Card 中，直接放在内容区顶部
2. **表格紧凑行高**：默认 48px，hover 时显示快捷操作
3. **批量操作栏**：选中后浮动显示，不占固定空间
4. **列宽优化**：客户名称 180px，行业 130px，规模 100px，来源 90px
5. **操作收敛**：操作列仅显示 `···` 更多按钮
