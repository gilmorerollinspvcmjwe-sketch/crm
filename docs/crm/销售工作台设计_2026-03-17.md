# 销售人员智能工作台设计

**项目路径**: `frontend-integrated`  
**设计日期**: 2026-03-17  
**版本**: V1.0

---

## 一、设计背景与目标

### 1.1 当前问题

现有 CRM 系统仪表盘主要面向管理人员设计，存在以下问题：

| 问题 | 现状 | 影响 |
|------|------|------|
| 视角偏差 | 偏向管理视角（统计图表、漏斗分析） | 销售人员找不到日常工作入口 |
| 功能分散 | AI 功能分散在各个独立模块 | 无法形成合力，使用率低 |
| 效率低下 | 高频操作需要多次点击 | 影响日常工作效率 |
| 缺乏个性化 | 统一的仪表盘布局 | 不适应不同角色的工作习惯 |

### 1.2 目标用户

- **一线销售人员**：需要快速查看待办、快速操作、跟进客户
- **销售主管/经理**：需要团队业绩概览 + 个人工作台

### 1.3 设计目标

让销售人员每天打开 CRM 第一眼就能看到**真正有用的信息**，快速开展工作：

1. **信息精准**：今日待办、智能推荐、个人业绩
2. **操作高效**：高频操作一触即达
3. **AI 可见**：主动推送建议，不用四处寻找
4. **个性定制**：可调整布局和显示内容

#### 5.2.3 实现方案

```typescript
// 赢单概率预测算法（简化版）
interface OpportunityScore {
  opportunityId: string;
  customerName: string;
  amount: number;
  stage: 'lead' | 'qualify' | 'proposal' | 'negotiation' | 'closed';
  winProbability: number;
  recommendation: string;
}

// 评分权重
const STAGE_WEIGHTS = {
  lead: 0.2,
  qualify: 0.4,
  proposal: 0.6,
  negotiation: 0.8,
  closed: 1.0
};

function calculateWinProbability(opportunity: Opportunity): number {
  // 基于阶段的基础分
  let score = STAGE_WEIGHTS[opportunity.stage];
  
  // 金额加分：金额越大，意向越强
  if (opportunity.amount >= 1000000) score += 0.15;
  else if (opportunity.amount >= 500000) score += 0.1;
  else if (opportunity.amount >= 100000) score += 0.05;
  
  // 跟进频率加分：最近 7 天有跟进
  if (opportunity.lastActivityDate && 
      daysBetween(opportunity.lastActivityDate, new Date()) <= 7) {
    score += 0.1;
  }
  
  // 客户历史成交加分
  if (opportunity.customer?.totalPurchases > 0) {
    score += 0.1;
  }
  
  return Math.min(score, 1.0);
}
```
