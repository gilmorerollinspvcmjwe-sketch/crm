## 🗺️ 升级路线图（10 周）

### Phase 1（第 1-2 周）- 基础组件统一
- ✅ 修复所有 TypeScript 错误
- ✅ 统一 Button/Input/Select 等基础组件
- ✅ 补充无障碍支持（ARIA 标签）
- ✅ 建立组件测试

**验收**: TypeScript 零错误，基础组件无障碍检查通过

### Phase 2（第 3-4 周）- 核心业务组件升级
- ✅ DataTable 全量替换（支持虚拟滚动）
- ✅ FilterBar API 统一（移除 Legacy 类型）
- ✅ DetailLayout 三栏布局应用
- ✅ 看板组件升级（视图保存）

**验收**: DataTable 支持 1000+ 行流畅滚动，FilterBar API 统一

### Phase 3（第 5-6 周）- 页面模板统一
- ✅ 11 个核心模块列表页统一
- ✅ 11 个核心模块详情页统一
- ✅ 表单页面统一（验证完善）
- ✅ 设置页面统一

**验收**: 所有核心页面使用标准模板，面包屑导航完整

### Phase 4（第 7-8 周）- 高级功能
- ✅ 暗黑模式完整支持（CSS 变量 + 组件适配）
- ✅ 键盘快捷键系统（Cmd+K、J/K、E/D）
- ✅ 性能优化（虚拟滚动、懒加载）
- ✅ 响应式优化（移动端适配）

**验收**: 所有组件支持暗黑模式，页面加载 < 2s

### Phase 5（第 9-10 周）- 测试与文档
- ✅ 单元测试覆盖率 ≥ 80%
- ✅ E2E 测试覆盖核心流程
- ✅ Storybook 组件文档
- ✅ CI/CD 部署流程优化

**验收**: 测试报告通过，Storybook 文档完整
