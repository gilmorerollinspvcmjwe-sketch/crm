## 三、剩余主要问题

### 1. types/index.ts 导出问题

**错误**: `Re-exporting a type when 'isolatedModules' is enabled requires using 'export type'`

**位置**: `src/types/index.ts` 多行

**解决方案**: 将所有类型导出改为 `export type`

### 2. CustomObject 页面类型不匹配

**错误**: Type '"text"' is not assignable to type 'FieldType'

**位置**: `src/pages/custom-objects/CustomObjectBuilder.tsx` 等多处

**原因**: 代码使用字符串字面量而不是 `FieldType` 枚举值

**解决方案**: 
- 方案 A: 使用 `FieldType.TEXT` 等枚举值
- 方案 B: 使用 `as FieldType` 类型断言
- 方案 C: 使用 `// @ts-ignore` 临时跳过

### 3. Services 中的 import type 问题

**错误**: `CustomObjectStatus` cannot be used as a value because it was imported using 'import type'

**位置**: `src/services/customObjectService.ts`, `workflowService.ts`

**解决方案**: 将 `import type { X }` 改为 `import { X }`

### 4. ConfirmDialog onConfirm 属性

**错误**: Property 'onConfirm' does not exist on type 'ConfirmDialogProps'

**位置**: 多个 custom-object 页面

**解决方案**: 为 `ConfirmDialog` 添加 `onConfirm` prop

### 5. 路由默认导出问题

**错误**: Property 'default' is missing in type 'typeof import(...)'

**位置**: `src/routes/index.tsx`

**原因**: 页面组件使用命名导出而不是默认导出

**解决方案**: 确保所有页面组件有默认导出
