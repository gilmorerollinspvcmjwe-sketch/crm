## 一、计费与定价模型

### 1.1 定价策略

参考 Salesforce（$0~$550/user/月）、HubSpot（免费+付费分层）、Zoho CRM（Standard→Ultimate）及 Pipedrive、Freshsales 的海外主流做法，采用 **Freemium + 分层订阅** 模型。

#### 1.1.1 版本划分与定位

| 版本 | 定价（年付） | 定价（月付） | 目标客群 | 定位 |
|------|-------------|-------------|---------|------|
| **Free（免费版）** | 免费 | 免费 | 个人/微型团队（≤3人） | 引流获客，降低试用门槛 |
| **Starter（入门版）** | $15/user/月 | $20/user/月 | 小型团队（≤10人） | 满足基本 CRM 需求 |

### 1.2 计费方式

#### 1.2.1 基础计费维度

- **按用户数计费**：核心计费单位为活跃用户数（已激活账号），非激活账号不计入。
- **按年付/月付切换**：年付享折扣（约 20%），鼓励年付提升现金流稳定性。
- **混合计费**：Enterprise 及以上支持按量计费（Pay-as-you-go）与套餐计费切换。

#### 1.2.2 附加计费项（Add-ons）

| 附加项 | 计费方式 | 说明 |
|--------|---------|------|
| 额外存储 | $2/GB/月 或 $20/GB/年 | 超出套餐配额后 |
| API 调用量包 | $10/10万次 | Starter/Pro 超出配额后 |
| AI Token 包 | $5/100万Token | AI 用量超出配额后 |
| 联系人超额 | $0.01/联系人/月 | 超出套餐上限后 |
| 邮件发送量 | $0.01/封 | 超出套餐上限后 |
| 坐席扩展包 | $50/坐席/月 | 客服场景扩编 |
| 自定义域名 | $10/域名/月 | 租户级自定义域名 |

#### 1.2.3 超额计费规则

1. **软限制（Soft Limit）**：达到 80% 配额时发送通知邮件，提醒用户升级或购买附加包。
2. **硬限制（Hard Limit）**：达到 100% 配额后，功能降级（如 AI 功能暂停），但核心数据不受影响。
3. **超额计费周期**：按自然月结算，超额部分次月计费。
4. **超限豁免**：每账户每季度有 1 次超限豁免机会（限 Starter 及以上）。

### 1.3 计费系统设计

#### 1.3.1 订阅管理状态机

```
[试用中] → (试用到期) → [待激活] → (完成支付) → [活跃] → (到期/取消) → [过期]
                ↓                              ↓
           (试用延长)                       (重新激活)
```

- 支持订阅暂停（最多 30 天，数据保留）。
- 支持订阅降级（次月生效，当前周期按高级别计费）。
- 支持订阅升级（立即生效，按剩余天数比例补差价）。

#### 1.3.2 账单生成

- **账单周期**：按月或按年生成账单。
- **账单内容**：用户数×单价 + 附加项 + 税费（按地区 VAT/GST）。
- **账单币种**：支持 USD/EUR/GBP/JPY/CAD/AUD 等多币种结算。
- **历史账单**：保留 7 年，支持 PDF 下载（满足财务合规要求）。

#### 1.3.3 支付集成

| 支付方式 | 提供商 | 说明 |
|---------|--------|------|
| 信用卡/借记卡 | Stripe | Visa/Mastercard/Amex/JCB |
| PayPal | PayPal | 主流支付方式 |
| 银行转账 | Stripe / 手工 | 大客户（> $5,000/月）|
| 数字钱包 | Stripe | Apple Pay / Google Pay |
| 本地支付 | 依区域 | iDEAL（荷兰）/ Klarna（欧洲）/ Alipay（东南亚）|

#### 1.3.4 发票管理

- 自动生成符合各国税法要求的电子发票。
- 支持企业抬头发票（需提交公司信息验证）。
- 支持 VAT/MOSS 申报（欧盟地区）。
- 发票通过电子邮件自动发送，支持管理后台下载。

#### 1.3.5 退款政策

| 场景 | 政策 |
|------|------|
| 首次订阅 14 天内 | 全额退款（参考 HubSpot、Freshsales）|
| 误付款 | 7 天内申请，全额退款 |
| 服务不可用 | SLA 未达标，按比例补偿（信用额度）|
| 常规退订 | 按剩余天数比例退款（年付）；月付不退 |

#### 1.3.6 试用期管理

- **免费试用**：Professional 版本提供 14 天全功能免费试用（无需绑定信用卡）。
- **延长试用**：销售团队可手动延长，最长 30 天。
- **试用数据保留**：试用期结束后数据保留 30 天，可随时激活订阅恢复。
- **试用转化提醒**：试用结束前 3 天/1 天/到期当天发送催转化邮件。

## 二、售卖与商业化

### 2.1 销售渠道

#### 2.1.1 自助注册（Self-service）

- 官网在线注册 → 选择版本 → 绑定信用卡 → 即时开通。
- 全程无需人工介入，适合技术型中小企业。
- 转化漏斗：注册 → 激活 → 首次使用 → 付费升级。

#### 2.1.2 销售团队（Sales-assisted）

- 针对 Enterprise 及以上级别，提供专属销售。
- 支持 demo 预约、定制方案报价。
- 销售 CRM 与本系统深度集成（商机管理→合同→订阅开能）。

#### 2.1.3 合作伙伴/渠道（Partner/Channel）

- **代理商计划**：授权代理商销售，按佣金（首次 20% + 续费 10%/年）分成。
- **ISV 集成合作**：与互补产品（如电商建站、客服平台）互相推荐。
- **OEM 合作**：将 CRM 能力嵌入其他产品销售。

#### 2.1.4 应用市场（Marketplace）

- Salesforce AppExchange、HubSpot Marketplace、Zoho Marketplace（双向集成）。
- Google Workspace Marketplace（内置入口）。
- Microsoft AppSource（与 Microsoft 365/Teams 深度集成）。

---

### 2.2 获客策略

#### 2.2.1 免费版引流 → 付费转化

关键转化节点：
- 联系人数达到 80% 上限时推送升级引导。
- AI 功能无法使用时展示付费版本价值。
- 报表导出版本提示（Free 无导出功能）。

#### 2.2.2 内容营销

| 内容类型 | 目标 | 分发渠道 |
|---------|------|---------|
| 博客文章 | SEO 获客 | 官网 + Medium + 行业站点 |
| 白皮书（CRM 选择指南）| 获客转化 | 官网表单下载 |
| 案例研究（Customer Story）| 建立信任 | 官网 + YouTube |
| 视频教程 | 激活 + 留存 | YouTube + TikTok |
| 播客（Sales Tips）| 品牌认知 | Spotify + Apple Podcast |
| 模板下载（Excel/Sheet 模板）| SEO + 品牌 | 官网 |

#### 2.2.3 SEO / SEM

- **SEO**：优化 "best CRM for small business"、"sales pipeline management" 等关键词。
- **SEM**：Google Ads + LinkedIn Ads，针对 "CRM software" 词组竞价。
- **对比页面**：与 HubSpot/Salesforce/Zoho 的对比页（"vs HubSpot" 系列），截流搜索流量。

#### 2.2.4 推荐计划（Referral Program）

- 被推荐人：首次付费后，获赠 1 个月免费。
- 推荐人：被推荐人每付费 1 个月，推荐人获得 $15 信用额度。
- 企业推荐：企业账户推荐其他企业，被推荐企业获得首年 20% 折扣。

### 2.3 客户生命周期管理

#### 2.3.1 生命周期阶段

```
注册 → 激活 → 试用/免费使用 → 付费转化 → 续费 → 扩展/增购 → （流失）
```

#### 2.3.2 各阶段关键指标

| 阶段 | 关键指标 | 健康基准 |
|------|---------|---------|
| 注册 | 注册率（独立访客→注册）| 3%~5% |
| 激活 | 7 日激活率（完成关键操作）| 40%+ |
| 试用 | 试用转化率 | 8%~15% |
| 付费 | 月订户增长率 | 逐月提升 |
| 续费 | 月续费率（MRR Churn）| >90%/月 |
| 增购 | NRG（净推荐收益增长率）| >100%/年 |

#### 2.3.3 流失预警与挽回

**预警信号**：
- 连续 14 天未登录。
- 关键功能使用率下降 >50%（对比 30 天均值）。
- 投诉工单或负面反馈。
- 竞品对比页面访问（通过 UTM 追踪）。

**挽回策略**：
- 14 天未登录：自动发送 re-engagement 邮件 + 30% 折扣优惠。
- 流失风险用户：触发客户成功经理（CSM）主动联系。
- 已流失用户：90 天内持续触达，提供迁移数据服务。

## 三、部署架构

### 3.1 部署模式

| 模式 | 说明 | 适用版本 |
|------|------|---------|
| **SaaS 多租户（默认）** | 共享基础设施，逻辑隔离 | Free/Starter/Professional/Enterprise |
| **私有部署** | 独立服务器/云账户 | Ultimate |
| **混合部署** | SaaS 主系统 + 本地敏感数据节点 | Enterprise（可选项）|

---

### 3.2 云平台

| 云平台 | 用途 | 区域 |
|--------|------|------|
| **AWS（主要）** | 主力云基础设施 | us-east-1（美）、eu-west-1（欧）、ap-southeast-1（亚太）|
| **Azure（备选）** | 微软生态集成（Teams/Outlook）| 美/欧/亚太 |
| **GCP（备选）** | 大数据/AI 计算 | 美/欧/亚太 |

**多区域部署**：用户数据按注册区域存储（合规要求），DNS 智能解析引导用户到最近节点，跨区域数据异步复制，RPO < 1 分钟。

### 3.4 多租户架构

#### 3.4.1 数据隔离方案

| 隔离级别 | 方案 | 适用场景 | 性能影响 |
|---------|------|---------|---------|
| **Schema 级** | 每个租户独立 PostgreSQL Schema | 中大型租户 | 低（共享连接池）|
| **Row 级** | tenant_id 列区分 + RLS 策略 | 小型租户（Free/Starter）| 中（索引依赖）|
| **数据库级** | 独立数据库实例 | 巨型租户（Enterprise 定制）| 高（完全隔离）|

**默认策略**：Schema 级隔离，Enterprise 及以上可申请 Row 级或数据库级隔离。

#### 3.4.2 租户配置管理

- 租户配置表（tenants）：存储版本、功能开关、配额上限、区域信息。
- 功能开关（Feature Flag）：按租户动态启用/禁用功能（使用 LaunchDarkly 或自建）。
- 配额管理：实时监控租户用量，超配额触发限流或降级。

#### 3.4.3 自定义域名

- Enterprise 及以上支持租户级自定义域名。
- 提供 CNAME 指向或 SSL 证书自动管理。
- 自定义域名绑定邮箱发送域名（SPF/DKIM/DMARC 配置）。

### 3.5 高可用与灾备

#### 3.5.1 高可用架构

| 层次 | 方案 | 说明 |
|------|------|------|
| 应用层 | Kubernetes Pod 多副本 + HPA | 自动扩缩容 |
| 数据库 | RDS Multi-AZ（主从自动切换）| 主节点故障自动切换 |
| 缓存 | Redis Cluster 或 ElastiCache Multi-AZ | 节点故障自动恢复 |
| 对象存储 | S3 跨区复制（CRR）| 单区故障不影响 |
| 消息队列 | RabbitMQ Mirror Queue / Kafka ISR | 副本同步 |

#### 3.5.2 备份策略

| 数据类型 | 备份频率 | 保留时间 | 恢复方式 |
|---------|---------|---------|---------|
| 数据库全量 | 每日 | 90 天 | 手动恢复 |
| 数据库增量 | 每小时 | 7 天 | 手动恢复 |
| 数据库 Binlog | 实时流复制 | 30 天 | 时间点恢复 |
| 文件存储 | 每日 | 90 天 | 手动恢复 |
| 配置备份 | 每次部署 | 30 天 | 自动恢复 |

#### 3.5.3 RPO / RTO 目标

| 级别 | RPO（最大数据丢失）| RTO（恢复时间）|
|------|-----------------|---------------|
| SaaS 默认 | < 5 分钟 | < 30 分钟 |
| Enterprise | < 1 分钟 | < 15 分钟 |
| Ultimate | 实时同步 | < 5 分钟 |

#### 3.5.4 灾难恢复计划（DRP）

- **同城双活**：主备区域自动切换（AWS Region 内多可用区）。
- **异地冷备**：跨区域灾备（eu-west-1 作为跨区备份）。
- **年度演练**：每年至少一次 DR 演练，验证 RPO/RTO。
- **通信预案**：灾难发生时通过 Status Page 和邮件通知客户。

### 4.1 通用集成能力

#### 4.1.1 REST API

- **规范**：OpenAPI 3.0（Swagger）规范，版本化管理。
- **认证**：OAuth 2.0（用户级）+ API Key（系统级）。
- **版本**：v1 当前 → v2 规划，旧版本 18 个月维护期后废弃。

- 重试策略：最多 5 次，指数退避（1s→2s→4s→8s→16s）。
- 事件日志：Webhook 投递历史保留 30 天。

#### 4.1.3 OAuth 2.0

- 支持 Authorization Code Flow（Web 应用）和 Client Credentials Flow（服务端）。
- Token 有效期：Access Token 1小时，Refresh Token 30 天（可滚动续期）。
- 权限范围（Scopes）：read / write / admin，按最小权限原则。

## 五、AI 能力规划

### 5.1 AI 基础设施

#### 5.1.1 LLM 集成架构

```
用户请求 → AI Gateway → 模型路由 → LLM Provider
                                 ↓
                          Token 计量 → 响应缓存 → 返回用户
```

| LLM Provider | 适用场景 | 模型 |
|-------------|---------|------|

| Google Gemini | 多模态（附件图片理解）| Gemini 1.5 Pro |
| Azure OpenAI（企业客户）| 数据不离开 Azure | GPT-4o |
| 自部署模型（Ultimate）| 数据完全自控 | Llama 3 / Mistral |

#### 5.1.2 模型路由策略

| 任务类型 | 推荐模型 | 策略 |
|---------|---------|------|

| 客户摘要（长）| GPT-4o | 质量优先 |

| 合规审核 | 自部署 Llama | 合规优先 |

#### 5.1.3 AI 基础设施特性

- **Token 用量管控**：每租户独立配额，接近上限时告警，超额自动降级。
- **AI 响应缓存**：基于客户 ID + 请求内容语义缓存，命中率约 30%。
- **流式输出（Streaming）**：支持 Server-Sent Events（SSE）。
- **PII 脱敏**：LLM 调用前自动检测并遮蔽（姓名/邮箱/电话/身份证/信用卡等）。

| 用户级时区设置 | 用户偏好设置存储 timezone 字段（IANA timezone ID）|
| 数据存储 | 所有日期时间以 UTC 存入数据库（带 timezone）|
| 显示转换 | 读取时按用户时区自动转换（API 层处理）|
| 报表时区 | 管理员可设置组织级默认时区（统一报表口径）|
| 时区边界 | 日期区间查询使用 UTC 边界计算，防止时区漂移 |
