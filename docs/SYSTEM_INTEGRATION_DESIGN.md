### 1.2 集成原则

| 原则 | 说明 | 实现方式 |
|------|------|---------|
| **CRM 作为客户数据中心** | 所有业务系统以 CRM 客户数据为权威来源 | 客户 ID 作为跨系统唯一标识，CRM 提供客户主数据 API |
| **围绕客户 360° 视图集成** | 各系统数据汇聚到客户统一视图 | 客户详情页整合 IM/工单/知识库/呼叫中心数据 |
| **双向数据同步** | 各系统数据实时/准实时同步至 CRM | Webhook + 消息队列，事件驱动同步 |
| **统一客户身份** | 跨系统客户身份统一映射 | 统一身份映射服务（Identity Mapping） |

### 1.3 现有集成现状

| 系统 | 现有集成页面/组件 | 技术实现 |
|------|-----------------|---------|
| 工单系统 | `src/pages/tickets/TicketList.tsx`（工单列表）<br>`src/components/Integration/TicketCard.tsx`（工单卡片） | 独立页面，Mock 数据 |
| 知识库 | `src/pages/knowledge/KnowledgeSearch.tsx`（知识搜索）<br>`src/components/Integration/KnowledgeCard.tsx`（知识卡片） | 独立页面，RAG 搜索集成 |
| 呼叫中心 | `src/pages/callcenter/OutboundTasks.tsx`（外呼任务） | 独立页面，Mock 数据 |
| IM | 尚无任何 CRM 集成 | 未实现 |

## 二、IM（即时通讯）集成方案

### 2.1 在 CRM 中的使用场景

| 场景 | 描述 | 业务价值 |
|------|------|---------|
| **客户详情页嵌入聊天** | 在客户 360° 视图中直接发起与该客户的 IM 对话 | 减少切换成本，提升响应速度 |
| **商机跟进活动记录** | IM 消息自动记录为商机/客户的跟进活动 | 完整跟进历史，自动生成活动记录 |
| **团队协作群组** | 针对特定商机/客户创建讨论群组 | 团队信息对齐，协作留痕 |
| **客户在线咨询** | 网站/App 访客发起 IM → 自动在 CRM 创建线索 | 营销获客自动化 |
| **IM 消息通知** | CRM 内的重要事件（新建商机、工单变更）通过 IM 推送 | 实时通知，即时响应 |

### 2.2 具体集成点

#### 2.2.1 客户详情页 — IM 对话历史卡片

**位置**：客户详情页右侧栏（关联信息区）

**功能**：
- 显示该客户最近 N 条 IM 对话记录（每条显示：时间、摘要、未读标记）
- 点击记录展开对话详情
- 点击「发起新对话」按钮，弹出 IM 聊天窗口（嵌入式 iframe 或 Web Component）
- 显示该客户关联的所有 IM 会话列表

#### 2.2.2 联系人详情页 — 一键发起 IM 对话

**位置**：联系人详情页左侧操作栏

**功能**：
- 「发起 IM」按钮（带消息图标）
- 点击后打开 IM 聊天窗口，自动填充联系人信息
- 支持选择已有会话或创建新会话

#### 2.2.3 活动时间线 — IM 消息作为活动类型

**位置**：客户/联系人/商机详情页中间区域活动时间线

**功能**：
- IM 消息作为独立活动类型展示（图标：`MessageOutlined`）
- 每条 IM 消息显示：时间、消息摘要、发送人
- 支持筛选「只看 IM」活动
- AI 自动摘要长对话（超过 N 条消息时）

#### 2.2.4 工作台 — 未读 IM 消息提醒

**位置**：工作台首页 Dashlet

**功能**：
- 「IM 消息」Dashlet 显示：未读消息数、来自客户的消息列表
- 点击跳转 IM 界面
- 支持标记已读/一键回复

#### 2.2.5 通知中心 — IM 消息通知

**位置**：顶部导航通知中心

**功能**：
- 新 IM 消息作为通知类型推送
- 通知内容：发送人头像 + 消息摘要 + 时间
- 点击跳转对应 IM 会话

### 2.3 数据流向

```
IM 系统                              CRM
─────────────────────────────────────────────────────────
│                                                        │
│  对话记录 ──Webhook──→ 客户活动时间线                   │
│  消息内容      (同步消息到 CRM，作为活动记录存储)          │
│                                                        │
│  客户信息 ←───API────  IM 侧边栏（客户信息卡片）          │
│  联系人列表    (CRM 提供客户/联系人数据给 IM 侧边栏展示)   │
│                                                        │
│  新建线索 ←───事件──── 客户发起咨询（来源标记为 IM）       │
│                                                        │
└────────────────────────────────────────────────────────
```

## 三、工单系统集成方案

### 3.1 在 CRM 中的使用场景

| 场景 | 描述 | 业务价值 |
|------|------|---------|
| **客户详情页查看工单** | 在客户详情页右侧栏显示该客户所有工单 | 一目了然客户的服务历史 |
| **联系人详情页查看工单** | 查看该联系人作为提交人/关联人的工单 | 追踪个人提交的服务请求 |
| **商机关联售前工单** | 售前技术支持工单与商机关联 | 售前成本核算，服务过程透明 |
| **客户满意度分析** | 工单解决率、响应时间 → 客户健康度 | 量化服务质量，指导客户运营 |
| **AI 流失预警** | 工单投诉频率 + 负面情绪 → 流失风险 | 提前预警，主动干预 |
| **一键创建工单** | 从客户/联系人页面直接创建工单 | 减少操作步骤，提升效率 |

### 3.2 具体集成点

#### 3.2.1 客户详情页右侧栏 — 工单列表卡片

**已有组件参考**：`src/components/Integration/TicketCard.tsx`

**当前实现**：独立的工单卡片，展示标题、状态、优先级、客户名、指派人、创建时间、标签。

**需增强**：
- 在 `TicketCard` 基础上增加「关联客户」字段筛选
- 在客户详情页右侧栏嵌入该客户的工单列表（最多显示 3 条，支持「查看更多」跳转）
- 每条工单显示：工单号、标题、状态 Tag、优先级 Tag、创建时间
- 点击工单卡片 → 弹出工单详情抽屉（不跳转页面，保持上下文）

**UI 示意**：
```
┌──────────────────────────────┐
│  工单 (5)              [查看全部]│
├──────────────────────────────┤
│ [URGENT] 系统故障无法登录      │
│ 紧急 | 张三 | 2026-03-24    │
├──────────────────────────────┤
│ [HIGH]  数据报表加载慢         │
│ 高优先 | 李四 | 2026-03-23   │
├──────────────────────────────┤
│ [MEDIUM]  功能咨询             │
│ 中优先 | 王五 | 2026-03-22   │
├──────────────────────────────┤
│         [+ 创建工单]            │
└──────────────────────────────┘
```

#### 3.2.2 一键创建工单

**位置**：
- 客户详情页右侧栏工单卡片底部「+ 创建工单」按钮
- 联系人详情页左侧操作栏

**功能**：
- 弹出工单创建表单抽屉（480px 宽）
- 表单自动填充当前客户/联系人的基本信息
- 支持选择工单类别（来自工单系统的分类体系）
- 提交后自动关联到当前客户

#### 3.2.3 仪表盘 — 工单统计 Dashlet

**位置**：工作台仪表盘

**功能**：
- 「工单统计」Dashlet 显示：
  - 待处理工单数（红色）
  - 处理中工单数（蓝色）
  - 今日新增工单数
  - 平均响应时间
  - 平均解决时间
  - CSAT（客户满意度）评分
- 点击跳转到工单列表（带对应状态筛选）

#### 3.2.4 报表中心 — 客户服务报表

**位置**：报表中心 → 客户服务报表

**功能**：
| 指标 | 说明 |
|------|------|
| 工单总量 | 按时间/客户/客服维度的工单数量 |
| 工单解决率 | 已解决工单 / 总工单数 |
| 平均首次响应时间 | 从创建到首次响应的平均时长 |
| 平均解决时间 | 从创建到关闭的平均时长 |
| CSAT 评分分布 | 非常满意/满意/一般/不满意/非常不满意 |
| 工单来源分布 | 按来源分类统计 |
| 高频问题 | 工单标题关键词统计 |

#### 3.2.5 AI 流失预警 — 工单投诉频率

**位置**：客户详情页 AI 分析面板 / 全局风险预警列表

**功能**：
- AI 检测逻辑：
  - 工单投诉频率 > 3次/月 → 黄色预警
  - 工单投诉频率 > 5次/月 → 红色预警
  - 工单中有负面关键词（退款、退货、投诉、差评）→ 触发流失风险
- 预警卡片显示在客户详情页「关系变化」区域
- 全局预警列表入口（设置 → 预警中心）

#### 3.2.6 联系人详情页 — 工单列表

**位置**：联系人详情页右侧栏

**功能**：
- 显示该联系人作为「提交人」或「联系人」的工单列表
- 与客户详情页工单卡片相同的展示形式

### 3.3 数据流向

```
工单系统                              CRM
─────────────────────────────────────────────────────────
│                                                        │
│  工单创建 ──Webhook──→ 客户活动时间线（自动记录）        │
│  工单状态变更   (工单打开/处理中/已解决/已关闭)            │
│                                                        │
│  工单关闭 ──Webhook──→ 触发客户满意度调查               │
│                                                        │
│  工单数据 ──API──────→ AI 流失预警模型（输入特征）       │
│                                                        │
│  客户信息 ←───API────  创建工单时自动填充客户信息        │
│  联系人列表                   （下拉选择/自动带出）       │
│                                                        │
└────────────────────────────────────────────────────────
```

### 3.4 API 设计（工单方向）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tickets?customerId={id}&page=1&pageSize=10` | 获取客户关联工单 |
| GET | `/api/tickets/:id` | 获取工单详情 |
| POST | `/api/tickets` | 创建工单（可指定 customerId/contactId） |
| PUT | `/api/tickets/:id/status` | 更新工单状态 |
| GET | `/api/tickets/stats?ownerId={userId}` | 获取工单统计（Dashlet 用） |
| GET | `/api/tickets/summary?customerId={id}` | 获取客户工单摘要（AI 用） |
| Webhook | `POST /api/webhooks/ticket` | 工单系统推送事件到 CRM |

## 四、知识库集成方案

### 4.1 在 CRM 中的使用场景

| 场景 | 描述 | 业务价值 |
|------|------|---------|
| **销售赋能** | 销售跟进客户时快速查找产品资料/案例 | 提升销售专业度，响应速度 |
| **客户自助** | AI 根据客户情况推荐相关知识库文章 | 减少客服压力，提升客户体验 |
| **AI 内容生成** | 基于知识库 RAG 生成邮件/话术/回复 | AI 赋能内容创作 |
| **新人培训** | 销售流程/话术知识库支撑新人成长 | 降低培训成本 |
| **商机技术文档** | 根据商机产品推荐对应的技术方案文档 | 提升售前效率 |

### 4.2 具体集成点

#### 4.2.1 工作台 — 知识库搜索入口

**位置**：工作台首页顶部搜索栏 / 左侧快捷入口

**功能**：
- 搜索框支持全文检索知识库文章
- 热门问题快捷标签（点击直接搜索）
- 搜索结果展示：文章标题 + 摘要 + 相关度分数
- 点击结果 → 右侧抽屉预览文章内容

#### 4.2.2 客户详情页 — AI 推荐相关知识库文章

**位置**：客户详情页右侧栏（新增「推荐文章」卡片）

**功能**：
- AI 根据客户行业、标签、近期活动推荐相关知识库文章
- 显示：文章标题 + 摘要 + 推荐理由
- 每篇文章可一键「发送给客户」（通过 IM 或邮件）
- 支持「查看全部」→「知识库搜索结果页」（带客户上下文）

**UI 示意**：
```
┌──────────────────────────────┐
│  推荐文章               [查看全部]│
├──────────────────────────────┤
│  互联网行业客户跟进话术指南     │
│  推荐理由：该客户属于互联网行业  │
│  [发送给客户] [查看详情]        │
├──────────────────────────────┤
│  企业级 SaaS 产品白皮书        │
│  推荐理由：该客户正在评估 ERP   │
│  [发送给客户] [查看详情]        │
├──────────────────────────────┤
│         [搜索更多...]           │
└──────────────────────────────┘
```

#### 4.2.3 商机详情页 — 产品技术文档推荐

**位置**：商机详情页右侧栏（新增「技术文档」卡片）

**功能**：
- 根据商机关联的产品，自动推荐对应的技术文档
- 支持下载/发送给客户/在线预览
- 文档分类：产品手册、API 文档、集成指南、常见问题

#### 4.2.4 AI 内容生成 — 基于知识库 RAG

**位置**：AI 功能模块 / 邮件撰写 / 跟进记录

**功能**：
- AI 邮件生成时，自动从知识库检索相关内容作为上下文（RAG）
- AI 话术推荐时，基于知识库最佳实践生成
- 知识库内容作为 AI 回复建议的参考来源
- 支持选择特定知识库分类作为 RAG 数据源

#### 4.2.5 侧边栏 — 知识库快捷搜索面板

**位置**：CRM 全局侧边抽屉（与 IM 面板并列 Tab）

**功能**：
- 独立的「知识库」Tab
- 分类浏览（产品文档/销售话术/客服指南/培训资料）
- 搜索历史记录
- 收藏的文章

### 4.4 API 设计（知识库方向）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/knowledge/search?q={query}&topK=5&objectType=customer` | 搜索知识库（可指定对象类型过滤） |
| GET | `/api/knowledge/recommend?customerId={id}&topK=3` | 获取客户推荐文章 |
| GET | `/api/knowledge/recommend?opportunityId={id}&topK=3` | 获取商机推荐文档 |
| GET | `/api/knowledge/articles/:id` | 获取文章详情 |

## 六、统一集成架构

### 6.1 集成方式

| 集成方式 | 适用场景 | 技术选型 |
|---------|---------|---------|
| **RESTful API** | CRUD 操作、数据查询 | HTTP JSON |
| **Webhook** | 事件通知、实时同步 | HTTP POST，尾部重试 |
| **消息队列** | 高频事件、大量同步 | RabbitMQ / Kafka |
| **嵌入式 iframe/Web Component** | IM 聊天窗口、知识库搜索面板 | postMessage 通信 |
| **SSO** | 统一身份认证 | OAuth 2.0 / SAML 2.0 |

### 6.2 统一客户视图

#### 6.2.1 客户 360° 视图数据整合

```
客户 360° 视图
├── 基本信息（CRM 自有）
├── 关联联系人列表（CRM 自有）

├── 关联合同列表（CRM 自有）

├── AI 概览摘要 ← AI 服务（综合所有数据）
└── 活动时间线 ← 统一汇总（IM + 工单 + 通话 + 邮件 + 跟进）
```

### 6.3 集成中间件设计

#### 6.3.1 统一事件总线

**职责**：
- 接收所有外部系统的 Webhook 事件
- 统一格式转换
- 路由到对应的 CRM 处理函数
- 事件日志记录（支持重放）

```typescript
interface IntegrationEvent {
  eventId: string;         // 全局唯一事件ID
  source: 'im' | 'ticket' | 'knowledge' | 'callcenter';
  eventType: string;        // 具体事件类型
  timestamp: string;        // 事件发生时间
  payload: object;          // 事件数据
  signature: string;        // 签名（防伪造）
}
```

#### 6.3.2 数据同步服务

| 数据类型 | 同步频率 | 同步方式 |
|---------|---------|---------|
| 工单状态变更 | 实时 | Webhook |
| 工单列表 | 准实时（5分钟） | 定时轮询 + Webhook 补数 |
| 通话记录 | 实时 | Webhook |
| IM 消息 | 实时 | Webhook |
| 知识库文章 | 准实时（30分钟） | 定时同步 + Webhook 增量 |
| 客户信息 | 实时 | CRM 为权威，双向同步 |

#### 6.3.3 身份映射服务
