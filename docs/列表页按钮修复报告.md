## 修复详情

### 修复模式 1：重复按钮 → 仅 DropdownMenu

**适用文件：**
- OpportunityList.tsx
- LeadList.tsx
- ContactList.tsx

**修复前代码：**
```tsx
cell: ({ row }) => (
  <div className="flex items-center gap-1">
    <Button onClick={() => navigate(`/xxx/${row.id}`)}>
      <Eye className="h-4 w-4" />
    </Button>
    <Button onClick={() => setEditModalOpen(true)}>
      <Edit className="h-4 w-4" />
    </Button>
    <DropdownMenu>
      <DropdownMenuTrigger asChild>
        <Button><MoreHorizontal /></Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem>查看详情</DropdownMenuItem>
        <DropdownMenuItem>编辑</DropdownMenuItem>
        <DropdownMenuItem>删除</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  </div>
)
```

**修复后代码：**
```tsx
cell: ({ row }) => (
  <DropdownMenu>
    <DropdownMenuTrigger asChild>
      <Button variant="ghost" size="sm" className="h-8 w-8 p-0">
        <MoreHorizontal className="h-4 w-4" />
      </Button>
    </DropdownMenuTrigger>
    <DropdownMenuContent align="end">
      <DropdownMenuItem onClick={() => navigate(`/xxx/${row.id}`)}>
        <Eye className="h-4 w-4 mr-2" />
        查看详情
      </DropdownMenuItem>
      <DropdownMenuItem onClick={() => setEditModalOpen(true)}>
        <Edit className="h-4 w-4 mr-2" />
        编辑
      </DropdownMenuItem>
      <DropdownMenuItem className="text-destructive" onClick={() => handleDelete(row.id)}>
        <Trash2 className="h-4 w-4 mr-2" />
        删除
      </DropdownMenuItem>
    </DropdownMenuContent>
  </DropdownMenu>
)
```

## 统一修改

所有修复的文件都进行了以下统一修改：

1. **操作列宽度调整**：`meta: { width: 80, fixed: "right" }`
2. **移除包裹层**：删除 `<div className="flex items-center gap-1">`
3. **移除独立按钮**：删除所有独立的图标按钮
4. **保留 DropdownMenu**：将所有操作移入 DropdownMenu 中
5. **添加图标间距**：DropdownMenuItem 中的图标添加 `mr-2` 类
